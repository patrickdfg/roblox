# roblox
로블록스 스튜디오 보물섬 모험 만들기 16차시 워크북 (코딩하루학원)

- `index.html` — A4 인쇄용 워크북. 표지 목차에서 **단계**를 누르면 그 단계까지 완성된 로블록스 파일(.rbxl)을 받습니다.
- `files/stage1.rbxl` ~ `files/stage8.rbxl` — 1~8단계 완성 파일 (2차시씩 묶음). 로블록스 스튜디오 **파일 → 열기**로 엽니다.

| 단계 | 차시 | 파일 |
|---|---|---|
| 1단계 보물섬의 시작 | 1·2 | files/stage1.rbxl |
| 2단계 섬 마을 만들기 | 3·4 | files/stage2.rbxl |
| 3단계 코드로 움직이는 섬 | 5·6 | files/stage3.rbxl |
| 4단계 위험한 섬 | 7·8 | files/stage4.rbxl |
| 5단계 보물을 모으자 | 9·10 | files/stage5.rbxl |
| 6단계 보물상자와 성문 | 11·12 | files/stage6.rbxl |
| 7단계 화면과 움직임 | 13·14 | files/stage7.rbxl |
| 8단계 완성과 게시 | 15·16 | files/stage8.rbxl |
